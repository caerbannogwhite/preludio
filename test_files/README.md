# test_files

Data and scripts used by the tests and the README.

- `Cars.csv` — the dataset every example reads
- `sas7bdat_test1.sas7bdat` — fixture for the `rsas!` builtin
- `examples.preq` — every README example; run by `Test_ScriptFiles`
- `literals.preq` — the literal forms of the language; run by
  `Test_ScriptFiles`
- `ideas/` — design sketches for syntax that does not exist yet
  (flow control, user-defined functions, `@`-indexing) and the original
  PRQL reference samples the grammar started from. Nothing in there
  runs.

`Cars1.csv` is written by the examples and ignored by git.
